BEFORE YOU RELY ON A ROUTE

Know what the status means.

Does “Route valid” mean I can buy this ticket?

No. It means the plan passes the route-derived checks implemented here. The planner does not check live schedules, seats, fares, booking classes, or whether a carrier will issue the ticket.

Is this the same as oneworld Explorer?

No. Global Explorer uses a distance-based fare. The separate oneworld Explorer fare is based on the continents visited. This tool covers Global Explorer only. See oneworld's fare overview for the product distinction.

What if a flight is missing?

The route snapshot can be incomplete or outdated. A missing suggestion does not prove a flight does not operate; check current schedules with the airline.

Where does my itinerary go?

Your working plan stays in this browser. A share link contains a compressed snapshot in the URL; anyone with that link can read the snapshot.

Use the published Global Explorer terms and confirm the full journey with the issuing carrier before making travel arrangements.
